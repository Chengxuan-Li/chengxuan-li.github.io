## Published facts

- Local dashboard relating Git branches, commits, worktrees, and Claude Code / Codex sessions.
- Git and agent sources are read-only; application-owned annotations and settings are mutable.
- Evidence-based agent states, including Unknown when observations are insufficient.
- Review states, tags, notes, checklists, annotation rules, named views, and dockable panels.
- Node.js service, React UI, TypeScript/Zod shared contracts, SQLite persistence, HTTP/SSE updates.
- Loopback service; optional GitHub pull-request overlay is off by default.
- MIT license and Windows-first release packages. The public site is documentation, not a hosted app.
