## 本地优先

repobs 只观测仓库与智能体文件，不修改这些源文件。审阅笔记、批注与设置保存在应用自身的本地数据库中。命名视图保留各自的筛选条件与隐藏项，可停靠面板支持按个人审阅习惯组织工作区。

## 技术细节

- **共享契约：** 通过 TypeScript 与 Zod 定义 Node.js 服务与 React 界面的交互边界。
- **实时观测：** 文件监听与受限轮询共同维护统一快照，通过 Server-Sent Events 向浏览器推送变更。
- **本地存储：** 使用 Node.js 内置的 SQLite 支持保存仓库登记、设置、批注及规则。
- **源文件隔离：** Git 检查仅调用白名单内的只读命令。服务运行于 `127.0.0.1`；可选的 GitHub 拉取请求只读视图默认关闭。

## 获取与文档

repobs 采用 MIT 开源许可，提供以 Windows 为主要平台的发行包。文档涵盖安装、配有截图的教程、状态语义、集成方式、架构及 HTTP API。项目也提供合成演示数据，便于了解界面与工作流程。
